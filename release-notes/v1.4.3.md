# Release Notes - MedCenter Manager v1.4.3

Version 1.4.3 brings a structural overhaul to invoice (factura) PDF generation and introduces dynamic multi-item invoice creation with real-time total calculation and improved form styling.

---

# Frontend

## Invoice PDF Structural Redesign

* **Dedicated Invoice Number Box:** Removed the "Factura Nº" column from inside the itemized billing table in `PdfService`. The invoice identifier is now rendered in a dedicated, high-visibility box (`FACTURA Nº: [number]`) positioned directly above the table.
* **Streamlined Two-Column Table:** Replaced the legacy table layout with clear `CONCEPTO` and `IMPORTE` columns.
* **Dynamic Multi-Item Rendering:** The PDF table now renders dynamic individual rows for each billed service item, with currency formatted according to locale standards (`XX,XX €`).
* **Summary & Compliance:** Retained a bold summary row for `Total servicios médicos` along with the comprehensive GDPR / LOPDGDD data protection clause spanning the table footer.

## Dynamic Invoice Form & Real-Time Calculation

* **Dynamic Line Items (`FormArray`):** Refactored `invoiceForm` in `PatientDetailComponent` to use an Angular `FormArray`, allowing medical staff to add multiple concept items with individual prices.
* **Row Addition & Removal:** Added a "+ Añadir línea" button adhering to the application design system (`.btn-secondary .btn-sm`), as well as row deletion buttons (`✕`) enabled when multiple lines are present.
* **Automatic Total Calculation:** Implemented a reactive getter `invoiceTotalAmount` that dynamically sums all line prices in real-time, displayed in an intuitive summary card at the bottom of the invoice section.
* **Form Reset & Validation Lifecycle:** Updated modal opening, closing, and flow selection routines (`resetInvoiceForm`) to ensure the invoice form is cleanly initialized with default concepts and validated reactively before PDF generation.

## PDF Manager Service Integration

* **Typed Multi-Item Support:** Updated `generateInvoiceWithJsPDF` in `PdfManagerService` and `PdfService` to accept structured `items` arrays while maintaining backwards compatibility.
* **Consent Coordinate Fine-Tuning:** Adjusted vertical coordinate positioning for procedure labels in consent templates.

## Styling & Dark Mode

* **Invoice Items Section Styles:** Added responsive SCSS rules in `patient-detail.component.scss` for `.invoice-items-section`, line item rows, concept/price columns, delete buttons, and the summary total card, fully compatible with both light and dark themes.
